## 🚀 Usage

### Building Custom MCP Servers

When building custom MCP servers for this project:

1. **Add bin entry to package.json**:
```json
{
  "name": "@cortiware/your-mcp",
  "bin": {
    "your-mcp-command": "./dist/index.js"
  }
}
```

2. **Add shebang to src/index.ts**:
```typescript
#!/usr/bin/env node
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
// ... rest of your code
```

3. **Build and link globally**:
```bash
npm run build
npm link
```

4. **Generate import JSON** for Augment:
```json
{
  "your-server-name": {
    "command": "npx",
    "args": ["your-mcp-command"],
    "env": {
      "YOUR_API_KEY": "your_key_here"
    }
  }
}
```

5. **Import to Augment**:
   - Copy the JSON above
   - In Augment VS Code extension, open MCP settings
   - Click "Import from JSON"
   - Paste the JSON
   - Restart VS Code

### Configuration

Add to your MCP settings (e.g., Claude Desktop config):

```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["github-mcp"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "your_token_here"
      }
    },
    "vercel": {
      "command": "npx",
      "args": ["vercel-mcp"],
      "env": {
        "VERCEL_TOKEN": "your_token_here"
      }
    },
    "neon": {
      "command": "npx",
      "args": ["neon-mcp"],
      "env": {
        "NEON_API_KEY": "your_key_here"
      }
    },
    "google-workspace": {
      "command": "npx",
      "args": ["google-workspace-mcp"],
      "env": {
        "GOOGLE_CREDENTIALS_PATH": "/path/to/credentials.json",
        "GOOGLE_TOKEN_PATH": "/path/to/token.json"
      }
    }
  }
}
```
